# Changelog

## 0.0.1

Initial release.

- 11ty v3 static wallpaper gallery with vanilla JS web components
- Folder-based theme organization under `wallpapers/`
- Automatic index generation with dimensions, tags, and size classification
- WebP thumbnail generation for image assets
- Search, theme filters, size filters, and favorites view
- Lightbox preview with keyboard navigation
- Copy URL and download actions on cards and in the lightbox
- Dark/light theme toggle
- GitHub Pages deployment via GitHub Actions
